**原生版与已发布的 Electron 桌面版是两个不同的应用**，功能集不同，本文的每一句只说原生版。Electron 版的说明见 [`PRIVACY.md`](../PRIVACY.md)。

## 1. 一句话概括

原生版不联网、没有账号、不含 AI、不含 OCR、不含电商连接器，也没有任何由开发者运营的服务器。你的业务数据只存在你自己的 Mac 上。

## 2. 数据存在哪里

原生版运行在 macOS 的 App Sandbox 容器里，业务数据是容器内的一个 SQLite 数据库文件：

```
~/Library/Containers/com.alotie418.sololedger/Data/Library/Application Support/SoloLedgerNative/sololedger.db
```

同一目录下还有附件文件（`attachments/docs/`）、备份（`Backups/`）与迁移过程中的工作文件。应用界面的「设置 → 数据」会原样显示这个路径。

**数据库文件本身没有被应用加密。** 保护它的是 macOS 的沙箱隔离与你的用户账户；如果你启用了 FileVault，磁盘层面还有全盘加密。请照常维护设备安全与自己的备份。

## 3. 联网行为：没有

原生版**不具备联网能力**，这不是一条承诺而是构建方式决定的：应用的 entitlements 是一个闭集，只有两项——App Sandbox 与「用户选择的文件读写」。macOS 的沙箱要求任何出站网络连接都必须持有 `com.apple.security.network.client`，而这一项不在集合里，因此**即使代码里写了联网也连不出去**。

由此直接得出：没有遥测、没有崩溃上报、没有 phone-home、没有自动更新检查、没有广告或分析 SDK。应用不发送任何东西。

（自动更新由 App Store 负责，那是系统行为，不是应用内的网络请求。）

## 4. 不含 AI、不含 OCR、不含电商连接器

原生版没有 AI 助手、不接任何模型服务商、不需要也不接受 API Key，没有图片/PDF 文字识别，也没有任何电商平台连接器。Electron 版的这些功能在原生版里**不存在**，不是「默认关闭」。

## 5. 文件读写：只在你选择的位置

应用不能自己浏览你的磁盘。凡是容器外的读写，都要经过 macOS 的文件选择面板（Powerbox）由你亲自指定位置，权限只在那一次操作内有效，应用不保留跨启动的访问书签。涉及的操作有：

- 导出备份（在你选的位置建一个文件夹，写入数据库与附件）
- 导出 CSV
- 导出诊断信息（见第 7 节）
- 从旧版数据文件夹迁移
- 从备份恢复

**导出去的文件归你自己保管。** 它们离开了应用的沙箱，应用之后既不会追踪也不会再访问它们；这些文件里含有你的业务数据，请按你自己的需要妥善存放。

## 6. 从旧版迁移

如果你之前用过 SoloLedger 的 Mac App Store 版，原生版会读取同一个沙箱容器里的旧数据库并迁入自己的数据目录；如果你用的是官网下载版，需要你通过第 5 节的文件选择面板把旧的数据文件夹指给它。

两种情况下**旧数据都是只读的**：迁移过程复制而不修改、不删除源文件。升级数据库结构之前会先写一份可读性经过校验的快照备份，写不出或读不回就不升级。

## 7. 诊断信息：只在你导出时产生，内容受限

当迁移或打开账本失败时，界面会提供「导出诊断信息」。它写出的是一个纯文本文件，内容限定在一份固定的字段清单内——应用版本、系统版本、数据库结构版本、失败的状态码与少量结构化参数——**不包含任何交易记录、附件内容、数据库内容或原始错误文本**，路径会被缩减到只剩文件名。这个文件由你选择保存位置，应用不会自动发送它。

一份实际导出的诊断文件长这样：

```
SoloLedger migration diagnostics
app: 1.1.0 (2)
os: ...
schema: —
db: <redacted>/sololedger.db
state: terminal
code: sourceCorrupt
classification: terminal
param.reason: integrityFailed
note: no transactions, attachments, or database contents are included.
```

## 8. 日志

应用向 macOS 的统一日志（Unified Logging）写入少量错误记录，错误详情按 `privacy: .private` 标记。这些记录留在你的 Mac 上，应用不读取也不发送它们。

## 9. 你对数据的控制

- **导出**：随时导出备份或 CSV，格式是开放的（SQLite 与 RFC 4180 CSV），不锁定在本应用里。
- **删除**：把上述数据目录整个删掉，业务数据就没有了；卸载应用时 macOS 会连同容器一起处理。
- **搬迁**：备份文件夹可以复制到另一台 Mac，用「从备份恢复」装回去。

## 10. 不收集、不出售

原生版不收集任何个人数据，因此也谈不上共享或出售。开发者手上没有你的业务数据副本。

Apple 作为分发渠道会按它自己的政策处理下载与购买相关的信息，那部分不在本应用的控制范围内，也不会流向本应用。
